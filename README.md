# Чайная лавка

Интернет-магазин чая — лабораторная работа по веб-программированию.

Сайт: https://enfantrich3.github.io/WEBlab1/

## Что умеет

- каталог товаров с ценами
- добавление товаров в корзину
- изменение количества и удаление товаров
- подсчёт итоговой суммы
- сохранение корзины в localStorage
- оформление заказа через форму в модальном окне
- адаптивная вёрстка для ноутбука, планшета и телефона

## Технологии

HTML, CSS, JavaScript без фреймворков.

## Структура

```
index.html       — страница магазина
css/style.css    — стили
js/data.js       — список товаров
js/script.js     — логика каталога, корзины и формы
images/          — картинки
```
